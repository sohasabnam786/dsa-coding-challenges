# 🧠 DSA & Coding Challenges

A comprehensive collection of Data Structures, Algorithms, and coding challenge solutions in **Python**.

Organized by topic, with clear explanations, time/space complexity analysis, and multiple approaches where applicable.

## 📂 Structure

```
├── arrays/            # Array manipulation problems
├── strings/           # String processing challenges
├── linked_lists/      # Linked list operations
├── stacks_queues/     # Stack and queue problems
├── trees/             # Binary trees, BST, traversals
├── graphs/            # Graph algorithms (BFS, DFS, etc.)
├── dynamic_programming/ # DP problems
├── sorting/           # Sorting algorithms & problems
├── searching/         # Binary search & variants
├── math_and_logic/    # Mathematical & logical puzzles
├── hashing/           # Hash map/set problems
├── recursion/         # Recursive solutions
├── greedy/            # Greedy algorithm problems
├── sliding_window/    # Sliding window technique
├── two_pointers/      # Two pointer technique
└── utils/             # Helper utilities & data structures
```
